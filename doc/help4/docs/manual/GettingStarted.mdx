# Getting started

When you first open PRSM 4, a short tour introduces the controls. You can
enter a name or use the suggested name. To see the tour again, open Help from
the map, use **reset the tour** on the [introduction](/manual/Introduction#see-the-tour-again),
then reload the map.

Enter a title at the top of the map. The arrow beside it opens the recent maps
and projects menu. The toolbar provides these actions:

- **Add factor:** select the button, click the map background, and enter a
  label.
- **Add link:** select the button and drag from one factor to another.
- **Undo**, **Redo** and **Delete:** reverse or repeat an edit, or delete the
  selected factors and links.
- **Share:** invite participants, open the data view, or make a copy.
- **Open** and **Save:** open or export files. See [Opening and saving
  maps](/manual/Files).
- **Search:** find factors by label.
- **Help** opens this manual; **Settings** opens the side panel.

Select a factor or link by clicking it. Drag a factor to move it, or drag
the background to pan the map. Double-click a factor or link to edit its
properties. A selected link can be dragged to change its curve. Use the
zoom controls to adjust magnification; double-click the map background to
fit the map in the window.

The settings panel has tabs for factor styles, link styles, network settings
and analysis. It can be moved by dragging its header. Select a factor or
link to view or edit its notes in the notes panel. Use **Share → Data View**
to work with factors and links in tables.

Changes made in a shared room are visible to other participants. Before
replacing a map with a file, remember that replacement affects everyone in
that room. [Sharing, copying and merging](/manual/Cloning) explains how to
make an independent copy or combine maps.
